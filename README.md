# 🎬 Netflix Data Analysis  

An end-to-end **data analysis project** exploring patterns, trends, and insights from **Netflix’s global catalog**.  
Using **Python**, **Pandas**, and **data visualization libraries**, this project uncovers meaningful stories behind Netflix’s movies and TV shows — including **genre trends, release years, and regional distributions**.  

---

## ✨ Features  

### 🧹 Data Cleaning & Preprocessing  
- Removed duplicates and handled missing data across columns like *director*, *country*, and *date_added*.  
- Converted date columns (e.g., `date_added`) into proper datetime format.  
- Extracted **release year**, **month**, and **content type (Movie/TV Show)** for better analysis.  

### 🔍 Exploratory Data Analysis (EDA)  
- Analyzed **content growth over time** — number of movies and shows added per year.  
- Identified **top genres** and **most active countries** contributing to Netflix’s catalog.  
- Explored **content ratings** (e.g., TV-MA, PG-13, R) to understand audience targeting.  
- Checked **movie vs. TV show** ratios and their global trends.  

### 📊 Visualizations  
- Created clean, interactive plots using **Matplotlib** and **Seaborn**, including:  
  - 📈 Year-wise content addition trend  
  - 🌍 Country-wise distribution of Netflix titles  
  - 🎭 Most common genres and categories  
  - ⏱️ Distribution of movie durations and show seasons  
  - 🧑‍🎬 Top directors and actors by number of titles  

### 💡 Insights by Dimensions  
- **Country Analysis** – The US and India dominate Netflix’s content library.  
- **Genre Analysis** – Dramas, comedies, and documentaries appear most frequently.  
- **Release Year Trends** – Sharp increase in new content after 2015, reflecting Netflix’s expansion.  
- **Content Type Ratio** – Movies outnumber TV shows, but original series are growing fast.  

---

## 🧠 Objectives  

- Understand how Netflix’s content catalog has evolved over the years.  
- Identify what type of content Netflix focuses on across different countries.  
- Examine viewing preferences through content ratings and genres.  
- Build strong data storytelling using visual analytics.
